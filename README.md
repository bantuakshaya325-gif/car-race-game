# Bike Game

A simple browser-based bike dodging game built with HTML, CSS, and JavaScript.

## How to run

1. Open the project folder.
2. Double-click `index.html` in a browser, or run it with a local web server.
3. Click **Start Game**.
4. Use the left and right arrow keys or A/D to move.

## Controls

- Left Arrow / A: move left
- Right Arrow / D: move right

## Files

- `index.html` — page layout
- `style.css` — styling
- `game.js` — game logic
